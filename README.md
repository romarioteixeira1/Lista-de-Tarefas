# Lista de Tarefas

Projeto feito com HTML, CSS e JavaScript puro, sem frameworks.

## Funcionalidades
- Adicionar tarefas (pelo botão ou com Enter)
- Marcar tarefa como feita
- Apagar tarefas
- Contador de tarefas pendentes
- Salva as tarefas no navegador (localStorage), então elas continuam lá depois de fechar a página
